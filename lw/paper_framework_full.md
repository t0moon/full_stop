# 论文框架整理：AIGC品牌视频广告的四层分析框架

本文件依据 [成稿.docx](/C:/Users/ws/Desktop/lunwen/lw/成稿.docx) 的现有内容进行结构化整理，目的不是替代成稿原文，而是把原文中已经形成的研究思路、理论支撑和分析方向收束为一个更清晰的论文框架。需要说明的是，下面出现的部分维度和指标属于在成稿论述基础上的方法化展开，便于后续写入研究设计或分析框架章节。

## 一、总体框架

从成稿内容看，本文的核心问题已经比较明确：不是讨论 AIGC 是否提升广告生产效率，也不是单纯比较 AIGC 与人工广告的优劣，而是考察 AIGC 品牌视频广告如何作为一种动态多模态商业文本来呈现、组织和建构品牌意义。

在理论上，成稿已经给出较清楚的组合路径：

1. 以张德禄多模态话语分析综合框架作为总体框架。
2. 以韩礼德三大元功能理论支撑语言模态分析。
3. 以 Kress 和 van Leeuwen 视觉语法支撑视觉模态分析。
4. 以模态协同理论解释语言、视觉、听觉之间的关系。

结合成稿中的研究对象和研究问题，全文框架可以整理为四层：

1. 语境层（Context）：解释广告处在什么传播处境中。
2. 表达层（Expression）：分析语言、视觉、听觉资源具体如何被调用。
3. 品牌形象呈现层（Brand Image Presentation）：判断广告重点建构了何种品牌意义。
4. 模态关系层（Modal Relations）：解释不同模态如何共同支撑或削弱品牌形象呈现。

四层之间的逻辑链条可以概括为：先判断广告在什么语境中运作，再分析它如何表达，再识别它最终呈现出什么品牌形象，最后解释这种品牌形象是如何由多模态协同建构出来的。

## 二、语境层（Context）

### 1. 层级定位

语境层对应多模态话语分析综合框架中的文化语境和情景语境。结合成稿内容，这一层不直接分析语言、画面或声音本身，而是先回答广告文本处在什么传播语境中、围绕什么品牌任务展开、主要面向何种传播目标。

语境层的作用主要有两点：

1. 交代 AIGC 品牌视频广告作为商业传播文本的基本传播处境，而不是把它仅仅看成技术生成产物。
2. 为后续表达层、品牌形象呈现层和模态关系层提供解释背景，说明不同模态资源为什么会以某种方式被组织起来。

### 2. 主要回答的问题

语境层主要回答以下问题：

1. 这支 AIGC 品牌视频广告首先服务于什么传播任务。
2. 广告的核心诉求更偏向功能说明、情感调动、身份象征还是价值表达。
3. 广告主要处在什么样的传播场景与传播链条之中。
4. 广告文本最终试图把品牌意义集中建构到什么重心上。

### 3. 可整理出的核心维度

可操作化时，语境层可整理为以下四个维度：

- 广告传播目标：品牌形象传播、产品推广、节点营销、事件传播、综合目标。
- 诉求导向：功能诉求、情感诉求、符号诉求、价值诉求、复合诉求。
- 传播场景：品牌官方发布、信息流传播、社交媒体扩散、电商促销场景、品牌活动节点、其他复合场景。
- 品牌传播重心：品牌理念、产品卖点、生活方式、技术创新、社会责任、综合重心。

### 4. 可直接放入论文的表述

语境层（Context）主要用于分析 AIGC 品牌视频广告所处的传播语境。本文认为，AIGC 品牌视频广告并非单纯的技术生成内容，而是一种服务于特定品牌传播任务的商业传播文本。因此，在进入语言、视觉和听觉模态分析之前，有必要先从语境层对广告的传播目标、诉求导向、传播场景和品牌传播重心进行识别。通过这一层的分析，可以判断广告首先服务于品牌形象传播、产品推广还是节点营销，可以区分其更偏向功能诉求、情感诉求、符号诉求还是价值诉求，也可以进一步明确广告主要嵌入的是官方发布、信息流传播、社交扩散还是活动节点等场景。语境层的意义在于为后续多模态表达分析提供背景说明，并为品牌形象呈现层和模态关系层奠定解释基础。

## 三、表达层（Expression）

### 1. 层级定位

表达层对应多模态话语分析中的表达层分析，是本文框架中最核心的操作层。成稿已经多次强调，视频广告中的品牌意义并不是依赖单一语言符号完成的，而是通过文字、画面、色彩、镜头、人物形象、背景音乐、音效和字幕文本等多种资源共同建构的。因此，表达层的重点是分析 AIGC 品牌视频广告具体“如何表达”。

这一层既承接前面的语境层，也为后面的品牌形象呈现层提供证据基础。换言之，语境层回答“为什么这样传播”，表达层回答“具体怎样表达”。

### 2. 主要回答的问题

表达层主要回答以下问题：

1. 广告主要调用了哪些语言资源、视觉资源和听觉资源。
2. 这些资源分别以什么方式组织叙事、传达信息和调动情感。
3. AIGC 视频广告在模态使用上是否呈现出某些相对稳定的表达特征。

### 3. 三个基本子维度

根据成稿已有表述，表达层可以划分为语言模态、视觉模态和听觉模态三部分。

#### 语言模态

语言模态主要关注文案、字幕、旁白、口号等资源如何承担信息传达、叙事推进和情感表达功能。结合成稿内容，可整理出的观察点包括：

- 品牌名称是否显性出现。
- 品牌口号或核心文案是否出现。
- 字幕使用的密度和覆盖程度。
- 语言模态主要是说明型、故事型、对话型还是宣言型。
- 文案措辞更偏理性说明、温暖治愈、激励动员还是奇观震撼。

#### 视觉模态

视觉模态主要关注画面如何塑造品牌意义。成稿明确提到，品牌意义往往依赖画面、色彩、镜头运动、人物形象和场景资源的组织方式。因此，视觉模态可重点观察：

- 广告的主导场景类型。
- 叙事中心是人物、产品、品牌符号还是复合主体。
- 画面的色彩基调和构图倾向。
- 镜头运动与剪辑节奏。
- 品牌标识和产品在画面中的露出方式。
- AIGC 是否突出超现实、奇观化、技术感等生成效果。

#### 听觉模态

听觉模态主要关注配音、音乐、音效和节奏如何参与品牌意义建构。结合成稿的已有论述，这一部分可整理为：

- 人声类型与语调特征。
- 背景音乐的风格取向。
- 音效在画面推进中的参与强度。
- 整体声音节奏是舒缓、均衡还是强刺激。

### 4. 表达层的操作化思路

表达层适合采用“片段层观察、视频层汇总”的方式处理。也就是说，可以先以镜头或场景片段及其对应的字幕、配音、音乐、音效为观察参照单位，再将各片段的信息统一汇总到单支广告的视频层变量中，最后对全部样本进行跨案例统计比较。这样既能保留多模态细节，又能避免全文写成逐案描述。

### 5. 可直接放入论文的表述

表达层（Expression）主要用于分析 AIGC 品牌视频广告中语言、视觉和听觉资源的具体使用方式。本文认为，品牌意义的形成并非依赖单一模态，而是通过文案、字幕、旁白、画面构图、色彩风格、人物形象、镜头运动、背景音乐和音效节奏等多种符号资源共同完成。因此，表达层将从语言模态、视觉模态和听觉模态三个方面展开，重点考察广告如何组织叙事、传达信息、调动情感并形成可识别的品牌表达方式。该层既是后续品牌形象呈现判断的直接依据，也是跨样本比较 AIGC 视频广告表达模式的核心部分。

## 四、品牌形象呈现层（Brand Image Presentation）

### 1. 层级定位

这一层是在成稿理论基础上的关键转化。成稿已经明确提出：考虑到研究对象是 AIGC 品牌视频广告，需要在既有多模态框架基础上，把原本较抽象的“内容层”进一步转化为“品牌形象呈现层”，使理论分析能够直接服务于后文的编码设计和研究问题展开。

因此，品牌形象呈现层的任务不是描述广告用了什么元素，而是进一步判断这些元素最终集中建构了何种品牌意义。

### 2. 主要回答的问题

品牌形象呈现层主要回答以下问题：

1. 广告文本重点突出了哪一种品牌形象。
2. 不同广告在品牌意义呈现上是否具有相对稳定的类型分布。
3. 语言、视觉、听觉资源最终共同指向了什么样的品牌认知框架。

### 3. 品牌形象的四个维度

结合成稿后段的研究切入点，本文可以将品牌形象呈现整理为四个维度：

- 功能形象：强调产品性能、技术优势、功效表现和实用价值。
- 情感形象：强调情绪共鸣、陪伴感、治愈感、温度和氛围体验。
- 符号形象：强调身份象征、生活方式、审美风格、社会角色和文化符号。
- 价值形象：强调理念立场、社会责任、公共价值、品牌精神和可持续诉求。

这一四分法与成稿最终研究方向是一致的，即把广告文本中的品牌意义落实到“功能形象、情感形象、符号形象和价值形象”四个观察维度上。

### 4. 与既有理论的关系

成稿在文献综述中引用了 Park、Jaworski 与 MacInnis 的品牌形象分类理论，强调品牌形象并非单一维度，而是与消费者需求结构和品牌意义建构密切相关。放到本文中，这一理论的意义不在于照搬消费者认知研究，而在于为广告文本中的品牌意义识别提供理论依据。因此，品牌形象呈现层可以理解为对既有品牌形象理论的研究性转化，即将原本偏认知结果的概念转化为偏文本呈现的分析维度。

### 5. 操作化思路

在操作层面，可将四类品牌形象分别设置为独立观察维度，并记录其在单支广告中的突出程度。若用于编码，可采用“未突出、一般突出、显著突出”的顺序尺度；若用于章节写作，也可采用“主导形象类型 + 次要辅助形象类型”的方式进行概括。

### 6. 可直接放入论文的表述

品牌形象呈现层主要用于判断 AIGC 品牌视频广告重点建构了何种品牌意义。与表达层不同，这一层不再停留于文案、画面和声音资源本身，而是进一步考察这些资源最终共同指向的是功能形象、情感形象、符号形象还是价值形象。本文认为，品牌形象在广告文本中不是静态标签，而是由多种模态资源持续组织和呈现出来的意义结构。因此，将“内容层”转化为“品牌形象呈现层”，有助于把多模态分析真正落到品牌传播问题本身，也使后续编码设计能够围绕品牌意义而非一般内容特征展开。

## 五、模态关系层（Modal Relations）

### 1. 层级定位

模态关系层主要用于解释语言、视觉、听觉之间如何发生协同。成稿中已经指出，多模态话语分析并不只关心单个模态各自表达了什么，更强调不同模态之间的联动机制。尤其对于视频广告这类动态视听文本而言，品牌意义往往不是由某一模态单独决定，而是由多模态关系共同建构出来的。

### 2. 主要回答的问题

模态关系层主要回答以下问题：

1. 语言与视觉之间是相互强化、相互补充还是彼此脱节。
2. 视觉与听觉之间是共同营造氛围，还是形成节奏和意义上的张力。
3. 语言与听觉之间是协同支撑同一品牌情绪，还是出现反差与断裂。
4. 整体多模态表达是否具有一致性和连贯性。

### 3. 核心关系类型

结合成稿中关于模态协同的表述，模态关系层可以整理为以下几类关系：

- 强化关系：不同模态共同强调同一品牌信息或情绪方向。
- 互补关系：不同模态分别承担不同功能，组合后形成完整意义。
- 协调关系：不同模态之间没有明显分工，但整体风格和节奏较一致。
- 弱关联或非互补关系：不同模态之间缺乏有效支撑，甚至彼此分离。

若进一步操作化，可分别观察语言-视觉关系、视觉-听觉关系、语言-听觉关系，并增加一个“整体模态协调度”的综合判断。

### 4. 与前面三层的关系

模态关系层不是孤立存在的，而是前三层的综合收束：

1. 语境层提供传播任务和品牌重心。
2. 表达层提供语言、视觉、听觉资源的具体证据。
3. 品牌形象呈现层指出这些资源最终呈现了什么品牌意义。
4. 模态关系层则进一步解释，这种品牌意义为何能够成立，或者为何会被削弱。

### 5. 可直接放入论文的表述

模态关系层主要用于分析语言、视觉和听觉资源之间的协同方式。本文认为，AIGC 品牌视频广告中的品牌意义并非由某一模态独立生成，而是在不同模态之间的强化、互补、协调或弱关联关系中被整体建构出来。因此，模态关系层将重点考察语言与视觉、视觉与听觉、语言与听觉之间的对应关系，并综合判断广告整体模态组织的协调度。通过这一层的分析，可以进一步解释品牌形象为何能够在广告文本中形成稳定呈现，也可以发现当前 AIGC 视频广告在多模态组织上存在的断裂和不足。

## 六、四层框架的整合表述

若将以上四层压缩为一段较完整的方法框架表述，可整理为如下文字：

本文以张德禄多模态话语分析综合框架为总体理论基础，并结合韩礼德三大元功能理论、视觉语法和模态协同理论，构建适用于 AIGC 品牌视频广告研究的四层分析框架。第一层为语境层，主要识别广告的传播目标、诉求导向、传播场景和品牌传播重心，用以说明广告文本所处的传播处境。第二层为表达层，主要从语言模态、视觉模态和听觉模态三个方面分析广告如何组织文案、画面与声音资源。第三层为品牌形象呈现层，在既有多模态“内容层”基础上进行研究性转化，用于判断广告重点建构的是功能形象、情感形象、符号形象还是价值形象。第四层为模态关系层，主要分析语言、视觉和听觉之间的强化、互补、协调或弱关联关系，以解释品牌意义如何在多模态协同中被整体建构。四层框架相互衔接，共同服务于对 AIGC 品牌视频广告品牌形象建构机制及其表达特征的研究。
